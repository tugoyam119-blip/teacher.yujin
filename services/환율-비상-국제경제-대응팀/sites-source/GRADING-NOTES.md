# 환율 비상: 가채점 변경 사항 (2026-10-19)

## 배점과 참여 근거

기존 점수 단계(경제 25/20/15/10, 정책 25/20/15/10, 국제기구 20/16/12/8,
국제협력 20/16/12/8, 활동·완성도 4/3/2/1, 시간 준수 6/4/2/0)를 유지한다.
별도 시간 가점, 목표 평균 보정, 총점 하한, 순위 보정은 없다.

완성도는 내용 정확도와 분리해 실제 선택·작성 수행을 인정한다. 다섯 서술과 구조화된
선택을 수행했다면 짧거나 전문용어가 부족하다는 이유만으로 완성도를 낮추지 않는다.
내용 평가의 명백한 오류·근거 부족은 기존 기준으로 판단한다. 학생이 보낸
`_processQuality` 같은 자기신고 값은 참여 증거로 사용하지 않는다.

서버는 앞으로 실제 서술 변경이 저장된 횟수와 변경 사이 120초 이하 구간만 누적한다.
동일 답안 자동저장·접속 유지·긴 공백·일시중단을 시간 근거로 누적하지 않는다.
작성 변화, 단계 진행, 반복이 아닌 작성 답안이 함께 확인될 때 기존 완성도 4점
범위에서 과정 근거를 인정한다. 이 수치는 실제 집중 시간이나 내용의 질을 보증하지
않으며, 교사 화면에 한계를 함께 표시한다.

이전 제출의 작성 이력은 소급 생성하지 않는다. 기록 없음은 미참여나 감점 사유가
아니며 `reviewRequired` 및 `reviewFlags`로 교사 확인을 요청한다. 결석자는 응시
기록을 만들거나 점수를 자동 부여하지 않는다. 중단·자동마감·추가시간은 확인
표시를 남긴다. 기존 추가시간 사용 감점과 기술 문제 면제를 유지하며 교사는 기존
점수 단계 안에서 시간 점수도 검토·확정할 수 있다. 기존 교사 확정점수는 유지한다.

현재 소스의 배점과 추가시간 안내를 점검한 결과 별도 가점을 추가하면 공지 배점과
충돌한다. 이번 변경은 배점을 유지하는 완성도 해석 보완이다. 학교에서 별도로
배부한 평가계획서는 저장소에 없어 일치 여부를 확인하지 못했다. 교사는 최종
확정 전에 해당 계획서와 과정 인정 근거를 확인해야 한다. 실제 학생 답안을
재채점하지 않았으므로 실제 평균이 90점 전후인지 검증하지 않았다.

## 전체 학생 일괄 가채점

- 선택 반 또는 전체 반의 제출 완료·교사 미확정 학생을 시작 시점에 고정한다.
- 기존 가채점은 새 기준 버전으로 검토한다. 답안·시간·과정·기준 버전이 모두 같은
  결과는 재사용한다. 교사 확정점수·피드백·변경 이력은 일괄 처리 대상에서 제외한다.
- 개별/일괄 가채점이 공유하는 D1 잠금으로 동시 AI 요청은 한 건으로 제한한다.
  AI 요청은 55초에 종료하며 잠금은 90초 후 복구 가능하다.
- 진행·성공·기존 결과 유지·보호/제외·실패를 학생별로 보존한다. 한 건 실패가
  나머지를 중단시키지 않는다. 완료 후 실패 건만 재시도할 수 있다.
- 화면이 다음 한 건씩 요청하는 방식이다. 화면 종료 후 무인 실행을 보장하지
  않는다. 현재 건 이후 대기하며 다시 열어 진행 상태 확인/이어하기가 가능하다.
- 처리 중 교사 확정·답안 수정·재개가 발생하면 조건부 저장이 오래된 결과를 거부한다.
- 정규/보충평가가 열려 있는 범위는 서버에서 실행을 막는다.
- 명단·답안·교사 점수를 삭제하거나 이관하지 않는다. 데이터베이스 변경은
  `CREATE TABLE IF NOT EXISTS`와 기존 답안 테이블의 기본값 있는 열 추가뿐이다.

## 검증 명령과 제한

`node --test tests/batch-grading.test.mjs tests/performance-regression.test.mjs tests/management-grading.test.mjs`

SQLite 메모리 DB와 가상 학생, 가짜 AI 응답으로 인증·범위·실패/재시도·캐시·중복
방지·확정점수 보호·동시 수정·참여 근거·내보내기를 검사한다. 실제 학생 데이터와
유료 AI 호출은 사용하지 않는다.

기존 50건 AI 벤치마크의 기준답안·기준점수는 변경하지 않았다. 과정 자기신고를
반영하던 이전 기준과 이번 완성도 해석의 차이는 교사가 검토해야 한다. 50건의
실제 AI 호출과 정확도 측정은 이번 검증에 포함하지 않는다.

Windows에서는 `node node_modules/vite/bin/vite.js build`로 운영 빌드를 검증했다.
전체 타입 검사는 기존 타입 오류 때문에 통과하지 않는다. 기존 문자열 기반 회귀
검사 7건도 원본에서 동일하게 실패한다. `rendered-html.test.mjs`는 Node에서
`cloudflare:` 모듈을 불러오지 못하며, 로컬 브라우저 미리보기는 Windows Workers
런타임 시작 오류로 검증하지 못했다. 빌드 성공을 브라우저 검증으로 간주하지 않는다.
