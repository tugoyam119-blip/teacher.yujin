유진T 클래스룸 서버형 등록용 실행 파일입니다.

실행: npm start
클래스룸에서 실행하면 학생용 수행평가로 바로 이동합니다.

교사 관리실 정보는 학생용 등록 파일에 표시되지 않습니다.
이 ZIP은 실제 수행평가 서버로 연결하는 실행 파일입니다.
수행평가가 업데이트되어도 클래스룸에 다시 등록할 필요가 없습니다.

교사용 진입 경로
- /teacher 및 /teacher/ → 기존 Sites 교사 관리실
- /?teacher=1 → 기존 클래스룸 등록 주소 호환용 교사 관리실
- / 및 /student → 학생용 수행평가
- yujint.app.json의 manage_path는 /teacher로 지정합니다.
교사 경로 선택은 인증을 대신하지 않으며, 실제 교사 인증은 기존 Sites가 처리합니다.
연결 시 쿼리 문자열은 목적지에 전달하지 않습니다.

검증: npm test
테스트는 임시 저장 경로만 사용하며 기존 답안 파일이 변경되지 않는지 확인합니다.
이 실행 파일은 /data의 기존 독립 서버 답안 파일을 읽거나 변경하지 않습니다.
Sites 데이터와 Railway 영구 볼륨은 별도로 보존하며 초기화·이관하지 않습니다.

실제 수행평가 소스 및 가채점 수정 (2026-10-19)
- 이 폴더의 server.js는 기존 Sites 연결 전용으로 그대로 유지합니다.
- 실제 채점 서버와 교사 UI의 검토 가능한 전체 소스는 sites-source/에 보관합니다.
- sites-source/SOURCE-ORIGIN.json에서 실제 Sites 커밋과 버전을 확인하세요.
- sites-source/GRADING-NOTES.md에 평가 기준, 데이터 보존 방식, 검증 범위와 한계를 기록했습니다.
- GitHub PR 병합 자체는 Sites 배포나 학생 데이터 이관을 실행하지 않습니다.
