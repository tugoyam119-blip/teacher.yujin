유진T 클래스룸 서버형 등록용 실행 파일입니다.

실행: npm start
기본 실행 주소(/)와 /student는 학생 화면으로 이동합니다.
/student 뒤에 쿼리 문자열이 있거나 마지막에 /가 붙어도 학생 화면으로 이동합니다.
/teacher는 교사 관리실로 이동하며, 쿼리 문자열이나 마지막 /가 붙어도 동일합니다.
알 수 없는 주소는 교사용 화면이 노출되지 않도록 학생 화면으로 안전하게 이동합니다.
/health와 학생명단 CSV 다운로드 및 검증 API는 기존대로 유지됩니다.

진입 경로 회귀 테스트: npm test

인증번호는 실행 파일이나 첫 화면에 표시되지 않습니다.
이 ZIP은 실제 수행평가 서버로 연결하는 실행 파일입니다.
수행평가가 업데이트되어도 클래스룸에 다시 등록할 필요가 없습니다.
