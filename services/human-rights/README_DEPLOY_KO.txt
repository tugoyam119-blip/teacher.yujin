인권도시 정책결정 수행평가 v9.1 CLOUD
====================================

이 버전은 선생님 노트북을 서버로 쓰지 않습니다.
한 번 Railway에 올리면 학생과 교사 모두 일반 HTTPS 주소로 접속합니다.
Tailscale / Cloudflare / PowerShell 서버창이 필요 없습니다.

[준비물]
1. GitHub 무료 계정
2. Railway 계정 (GitHub로 로그인 가능)
3. 이 ZIP 압축 해제 폴더
4. OpenAI API 키는 AI 가채점을 쓸 때만 필요

------------------------------------
A. GitHub에 파일 올리기 (무료)
------------------------------------
1. https://github.com 에 가입/로그인
2. 오른쪽 위 + → New repository
3. Repository name: hr-city-class (예시)
4. Private 선택 권장
5. Create repository
6. Add file → Upload files
7. 이 ZIP을 압축 해제한 뒤, 그 안의 모든 파일/폴더를 업로드
   - package.json
   - server.js
   - railway.json
   - public 폴더
   - seed 폴더
   - CSV 파일 등
8. Commit changes

중요: OpenAI API 키는 GitHub에 절대 올리지 마세요.

------------------------------------
B. Railway에 배포하기
------------------------------------
1. https://railway.com 에 접속
2. Login → GitHub로 로그인 권장
3. New Project → Deploy from GitHub repo
4. 방금 만든 hr-city-class 저장소 선택
5. Deploy Now
6. 배포 로그에 "HR CITY v9.1 listening on ..."가 나오면 서버 실행 성공

------------------------------------
C. 학생 답안을 영구 저장할 Volume 만들기 (필수)
------------------------------------
Railway 프로젝트 화면에서 서비스 타일을 선택하거나 우클릭 → Add/Attach Volume
Mount Path를 정확히 아래처럼 입력:

/data

이 Volume이 없으면 Railway가 재배포될 때 학생 데이터가 사라질 수 있습니다.
Free 플랜도 0.5GB Volume을 지원하며 이 수행평가 텍스트 데이터에는 충분한 크기입니다.

Volume을 붙인 뒤 서비스가 자동 재시작됩니다.

------------------------------------
D. 교사용 PIN 설정 (강력 권장)
------------------------------------
서비스 → Variables에서 새 변수 추가:

TEACHER_PIN=원하는숫자

예: TEACHER_PIN=592487

인터넷에 공개되는 서버이므로 1234 그대로 쓰지 않는 것을 권장합니다.
교사용 브라우저에서는 한 번 입력한 PIN을 기억하므로 매번 입력할 필요가 없습니다.

변수를 추가하면 Railway가 다시 배포/재시작할 수 있습니다.

------------------------------------
E. 고정 학생 주소 만들기
------------------------------------
서비스 → Settings → Networking → Generate Domain

예시 주소:
https://hr-city-class-production.up.railway.app

이 Railway 주소는 고정해서 계속 사용할 수 있습니다.
별도 도메인을 구매하지 않아도 됩니다.

학생용 주소:
https://발급주소.up.railway.app/

교사용 주소:
https://발급주소.up.railway.app/teacher

처음 교사용 화면에 들어가면 C/D에서 설정한 교사용 PIN을 1회 입력합니다.
같은 브라우저에서는 이후 기억합니다.

------------------------------------
F. 첫 수업 전 확인
------------------------------------
1. 교사용 주소 접속
2. 기본 명단 ON / 179명 확인
3. 000000 테스트 계정으로 학생 화면 확인
4. 교사용 화면 → 1반 → 1차시 개방
5. 학생용 주소에서 000000으로 입장
6. 자료/저장/타이머 확인
7. 테스트 완료 후 실제 반을 개방

000000 테스트 계정은 로그인할 때마다 이전 테스트 진행/제출 데이터가 초기화됩니다.

------------------------------------
G. AI 가채점
------------------------------------
배포 후 교사용 화면의 AI 가채점 카드에서 기존처럼 OpenAI API 키를 붙여넣고
"API 키 저장·연결 확인"을 누르면 됩니다.

Volume(/data)이 붙어 있으면 AI 설정도 서버 재시작 후 유지됩니다.
기본 모델: gpt-5.6-luna

원하면 Railway Variables에 아래 값을 넣어도 됩니다.
OPENAI_API_KEY=sk-...
OPENAI_GRADING_MODEL=gpt-5.6-luna

단, API 키는 GitHub 파일에는 절대 쓰지 마세요.

------------------------------------
H. 교실 컴퓨터에서 진행상황만 보기
------------------------------------
교사용 화면에서 "교실 모니터 열기" 버튼을 누르면 읽기 전용 모니터가 새 탭에서 열립니다.
그 주소를 교실 PC에 복사해 사용할 수 있습니다.

------------------------------------
I. 비용
------------------------------------
Railway는 처음 30일 $5 Trial 크레딧을 제공합니다.
Trial 이후 Free 플랜은 월 $1의 리소스 크레딧이 있으며 0.5GB Volume을 지원합니다.
이 앱은 텍스트 중심의 작은 Node 서버라 우선 Free 플랜에서 시험해보는 것을 권장합니다.
실제 사용량이 무료 크레딧을 넘거나 더 안정적인 운영이 필요하면 Hobby($5/월)로 올리면 됩니다.

별도 .kr/.com 도메인은 필요 없습니다.
Railway가 제공하는 *.up.railway.app 주소를 그대로 사용하면 됩니다.

------------------------------------
J. 개인정보 주의
------------------------------------
이 버전은 학생 학번/이름/답안을 외부 클라우드(Railway)에 저장합니다.
실제 수행평가에 사용하기 전에 학교의 외부 클라우드/개인정보 저장 지침을 확인해 주세요.
학교 정책상 이름 저장이 제한되면 명단을 익명 코드 방식으로 바꾸는 것이 좋습니다.

------------------------------------
문제 발생 시 확인
------------------------------------
Railway 서비스 → Deployments / Logs에서 오류 문구 확인
정상 상태 확인 주소:
https://발급주소.up.railway.app/health

정상이면:
{"ok":true,"version":"v9.1"}



[v9.1 추가 기능]
- 교사용 화면의 "시범·활동 기록 전체 초기화" 버튼으로 진행·답안·접속·시간·제출·채점 기록을 한 번에 삭제할 수 있습니다.
- 기본 179명 명단, 명단 검증 설정, OpenAI API 키, Railway TEACHER_PIN은 유지됩니다.
- 초기화 시 서버 초기화 번호가 갱신되어 학생 기기에 남은 이전 임시저장도 다시 서버로 복구되지 않습니다.
- 실제 참여 인원은 명단 전체가 아니라 실제 접속/진행 기록이 생긴 학생만 집계합니다.
