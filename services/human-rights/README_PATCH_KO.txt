인권도시 정책결정 수행평가 v11.5 자동패치

이번 버전의 목적
- 학생용 수행평가 내용과 평가 구조는 유지합니다.
- 서버 관리, 교실에서의 실제 진행, 프로젝터 공개화면을 분리해 교사의 수업 운영을 편하게 합니다.
- 서버가 열려 있는 시간과 학생의 실제 수행시간을 분리합니다.

화면 구성
1. /teacher  서버·기록 관리실
   - 반/차시 선택, 학생 입장 개방·종료
   - 명단·제출·저장·가채점·기록 확인
   - 실제 수업 시작/일시정지/재개는 /operate에서 진행

2. /operate  교실 운영실
   - 실제 수업 중 교사가 띄워두는 운영 전용 화면
   - 수행 시작·일시정지·재개
   - 실제 수행시간 45분 도달 시 자동 일시정지
   - 자동 일시정지 뒤 +5분 계속 또는 새 45분 세션으로 재개 가능
   - 학생 자율 추가 개방시간(기본 5분, 1회) 열기/닫기
   - 접속/제출/도움 요청/5분 이상 활동 없음/저장 이상/추가시간 사용 현황
   - 학생 이름을 누르면 현재 STEP, 마지막 활동, 저장 상태, 답안 글자 수, 사용시간 등 상세 확인
   - 전체 STEP 분포는 집계로 표시하고 학생별 STEP은 기본 목록에서 숨김
   - 전체 학생에게 짧은 안내 전송 가능

3. /classroom  교실 공개화면
   - 프로젝터/전자칠판용 화면
   - 시작 전에는 수행평가 개요·방법·주의사항 표시
   - 진행 중에는 현재 반/차시, 실제 수행시간, 접속/제출 수, STEP 분포, 교사 안내 표시
   - 개별 학생 이름이나 개인 진행상황은 표시하지 않음

권장 수업 운영
1. 교무실 또는 수업 직전에 /teacher 또는 /operate에서 해당 반과 차시를 선택합니다.
2. `학생 입장 열기`를 누릅니다. 학생은 로그인할 수 있지만 수행시간은 흐르지 않습니다.
3. 교실 프로젝터에는 /classroom을 띄우고 수행평가 개요를 설명합니다.
4. 설명과 접속 확인이 끝난 뒤 /operate에서 `수행 시작`을 누릅니다.
5. 실제 수행 중 필요한 경우 수동으로 일시정지할 수 있습니다.
6. 실제 수행시간이 45분에 도달하면 자동으로 일시정지됩니다. 필요하면 교사가 +5분 계속 또는 새 45분 세션으로 재개할 수 있습니다.
7. 1차시가 끝나면 일시정지 상태로 두고, 다음 차시에 설명 후 재개합니다. 일시정지 중 시간은 누적되지 않습니다.
8. 정규 수행이 끝난 뒤 짧게 마무리할 학생이 있다면 /operate에서 `학생 자율 추가시간`을 엽니다.
9. 필요한 학생이 자신의 화면에서 `추가 개방시간 사용`을 눌러 기본 5분을 1회 사용할 수 있습니다. 추가시간은 정규 수행시간과 별도로 기록됩니다.
10. 수업이 완전히 끝나면 학생 입장을 닫습니다.

학생 도움 요청
- 학생 화면의 `🙋 선생님 도움 요청`에서 사유를 선택해 요청할 수 있습니다.
- /operate에 새 요청이 표시되고 알림음이 납니다.
- 교사가 학생을 확인한 뒤 요청을 처리 완료로 바꿀 수 있습니다.

운영 보조
- 5분 이상 의미 있는 활동이 없는 학생은 별도 경고로 표시됩니다.
- 저장 상태가 비정상인 학생만 경고로 표시됩니다.
- STEP 분포는 반 전체 집계로 확인합니다.
- 교실 공개화면에는 개인 이름·개인 STEP을 노출하지 않습니다.
- 교사 전체 안내는 학생 화면 상단에 잠시 표시됩니다.

유지되는 핵심 기능
- 179명 기본 명단
- 학생 자동저장 및 수동 임시저장
- 최종 제출 전 최신 수동 임시저장 요구
- 최종 제출 후 수정·재제출 잠금
- 교사용 테스트 계정 000000 우회
- 제출 후 자기평가 및 수행시간 제외
- /data 영구 저장 구조
- 자료 이미지 확대, STEP 2 자료 바로보기, STEP 4 사고흐름, STEP 6 재판단 비교

운영 주소
- 학생용: /
- 서버·기록 관리: /teacher
- 교실 운영실: /operate
- 교실 공개화면: /classroom
- 상태 확인: /health
