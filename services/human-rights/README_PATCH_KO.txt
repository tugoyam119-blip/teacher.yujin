인권도시 정책결정 수행평가 v12.0 자동패치

이번 버전의 목적
- 교사가 매 반마다 ‘서버 열기 → 학생 입장 열기 → 수행 시작’을 반복하던 운영 흐름을 단순화합니다.
- ‘전체 학생이 사이트에 접속할 수 있는 상태’와 ‘현재 반이 실제 수행을 할 수 있는 상태’를 명확히 분리합니다.
- 학생 모바일 화면에서 수행평가 미리보기 버튼이 하단 내비게이션과 겹치지 않도록 위치를 바꿉니다.

핵심 변경
1. 전체 학생 서버는 한 번만 열기
   - /teacher와 /operate에서 ‘전체 반 서버 열기’를 한 번 누르면 1~7반 학생 모두 로그인할 수 있습니다.
   - 반이 바뀌어도 서버를 다시 열 필요가 없습니다.
   - 서버가 열려 있는 것만으로는 수행시간이 흐르지 않습니다.

2. 실제 수행은 반별 원클릭 시작
   - /operate에서 반과 차시를 선택하고 ‘선택한 반 수행 시작’을 누르면 즉시 해당 반의 수행과 타이머가 함께 시작됩니다.
   - 기존의 ‘학생 입장 열기 → 수행 시작’ 두 단계를 없앴습니다.
   - 일시정지·재개·45분 자동정지·추가시간은 기존과 동일합니다.

3. 현재 반 종료 후 서버 유지
   - ‘현재 반 수행 종료’를 눌러도 전체 학생 서버는 열린 상태로 유지됩니다.
   - 다음 반은 반·차시를 선택하고 수행 시작만 누르면 됩니다.
   - 전체 서버 닫기는 수업이 모두 끝난 뒤 한 번만 하면 됩니다.

4. 학생 대기 화면
   - 전체 서버가 열려 있으면 자기 반 수행 전에도 로그인할 수 있습니다.
   - 자기 반이 아닐 때는 ‘우리 반 수행 시작 전’ 대기 화면만 보이고 답안 저장·제출은 열리지 않습니다.
   - 다른 반 수행 중 안내나 추가시간이 다른 반 학생에게 노출되지 않습니다.

5. 수행평가 미리보기 버튼 위치 수정
   - 화면 오른쪽 아래 고정 버튼을 제거했습니다.
   - ‘개념 / 도움 요청 / 정책 보드’가 있는 상단 도구 영역에 ‘미리보기’를 함께 배치했습니다.
   - 모바일 하단 이전·자료·저장·다음 버튼과 겹치지 않습니다.

유지되는 기능
- v11.9 사전 튜토리얼 완료현황, TRADE-OFF 사례연습, 서술구조 연습, STEP별 개념 도움
- 처음 운영하는 선생님 모드
- 반별 독립 수행시간, 45분 자동 일시정지, 학생 자율 추가시간
- 자동저장·임시저장·최종제출 잠금·AI 가채점
- 기존 평가 문항·배점·답안 검증 규칙

권장 실제 운영
1) 수업 시작 전 /operate에서 ‘전체 반 서버 열기’ 1회
2) 학생은 미리 로그인하거나 /guide 확인
3) 설명 후 반·차시 선택 → ‘수행 시작’ 1회
4) 수업 종료 → ‘현재 반 수행 종료’
5) 다음 반에서는 3~4만 반복
6) 하루 수업이 모두 끝나면 ‘전체 서버 닫기’ 1회
