인권도시 정책결정 수행평가 v11.6 자동패치

이번 버전의 목적
- 학생 수행평가의 자료·문항·평가 구조는 변경하지 않습니다.
- v11.5 교실 운영 기능을 실제 여러 반 수업에 맞게 안정화합니다.
- 각 반의 1차시·2차시 실제 수행시간을 서로 독립적으로 저장하고 공개화면에서 반별로 확인합니다.

핵심 변경
1. 반별 독립 수행시간
   - 1~7반의 1차시, 2차시 시간이 각각 별도로 저장됩니다.
   - 다른 반을 열어도 이전 반의 시간은 유지됩니다.
   - /classroom 상단의 1~7반 탭으로 각 반의 기록을 바로 확인할 수 있습니다.
   - 공개화면에는 1차시 시간 / 2차시 시간 / 정규 수행 누적시간을 함께 표시합니다.

2. 45분 자동 일시정지 안정화
   - 자동 일시정지는 반드시 설정된 기준시간(기본 45:00)에 정확히 고정됩니다.
   - v11.5에서 자동정지 뒤 시간이 계속 증가해 589:15처럼 보일 수 있던 기존 과대시간은 v11.6 최초 로딩 때 자동으로 00:00으로 복구합니다.
   - 정상적으로 +5분 또는 +45분 연장한 경우에는 확장된 기준시간을 그대로 존중합니다.

3. 현재 반·차시 시간만 초기화
   - /operate에서 `이번 차시 00:00` 버튼을 제공합니다.
   - 학생 답안·제출·접속 기록은 지우지 않고 교실 운영용 시간만 초기화합니다.
   - 수행시간이 진행 중일 때는 실수 방지를 위해 초기화할 수 없습니다.

4. 1차시·2차시 공개화면 분리
   - 1차시: 자료 5개 확인 → 근거 저장 → 50억 정책 설계 → 권리와 이유 연결
   - 2차시: 지난 정책 확인 → 정책 영향·trade-off → 새 정보 재판단 → 최종 정책·제출
   - 보충 수행: 저장된 지점에서 이어하기 → 남은 단계 마무리 → 저장 후 제출

5. 교실 운영 안정화
   - `활동 없음` 경고를 5분에서 7분으로 변경하고 실제 수행 중일 때만 표시합니다.
   - 학생 자율 추가시간 사용자가 남아 있을 때 차시 종료를 누르면 학생명과 남은 시간을 경고합니다.
   - 교실 운영실 상단에 현재 상태에 맞는 `다음 행동`을 안내합니다.
   - 새 차시를 열 때 해당 반의 지난 도움 요청은 자동 정리됩니다.

화면 역할
- /teacher : 서버·명단·기록·채점 관리 + 7개 반 시간 현황
- /operate : 실제 수업 진행, 도움 요청, 진행 분포, 시간·추가시간 운영
- /classroom : 프로젝터/전자칠판 공개화면 + 반별 시간 선택
- / : 학생 수행평가

- 최종 제출 전 최신 수동 임시저장 요구
