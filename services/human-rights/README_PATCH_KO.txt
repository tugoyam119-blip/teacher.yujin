인권도시 정책결정 v9.2 패치

변경 내용
1. 교사용 학생현황 기본 필터를 '활동 학생만'으로 변경
2. 아직 접속/활동하지 않은 기본명단 학생은 처음 화면에서 숨김
3. 필요할 때 필터에서 '전체 명단'을 선택하면 179명 전체 확인 가능
4. '나감'은 실제 활동 후 나간 학생만 표시
5. '미제출'은 실제 활동 중이지만 아직 제출하지 않은 학생만 표시
6. 교실 읽기 전용 모니터에도 같은 필터 방식 적용
