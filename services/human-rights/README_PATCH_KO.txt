인권도시 정책결정 수행평가 v11.9 자동패치

이번 버전의 목적
- v11.8의 학생 사전 튜토리얼과 교실 설명 모드를 유지합니다.
- 대규모 모의 운영에서 남은 문제였던 튜토리얼 미열람, TRADE-OFF 이해, 서술 구조 부담, 수행 중 개념 재확인을 보완합니다.
- 실제 평가 문항·배점·시간 계산·답안 검증·최종 제출 규칙은 변경하지 않습니다.

핵심 변경
1. 사전 튜토리얼 준비 완료 저장
   - 확인문제 10개를 모두 맞힌 뒤 학번·이름으로 준비 완료를 저장합니다.
   - 점수에는 반영하지 않습니다.
   - /operate에서 1~7반별 완료 인원·비율·미완료 학생을 확인합니다.

2. TRADE-OFF 사례형 연습
   - 실제 수행평가와 다른 학교 쉼터 사례로 ‘후순위 집단은 반드시 피해자가 아니다’를 상황판단으로 연습합니다.

3. 일반 서술 구조 연습
   - 내 판단 → 관련 자료 → 기준·권리 → 결론의 논리 구조를 실제 답안과 무관한 예시로 연습합니다.

4. 수행 중 짧은 개념 도움
   - 학생 화면의 ‘❓ 개념 도움’에서 현재 STEP에 맞는 일반 설명만 10~20초 안에 다시 확인합니다.
   - 특정 역·집단·정책을 정답으로 추천하지 않습니다.

5. 유지되는 핵심 기능
   - v11.8 /guide 학생 복습·교실 설명 모드
   - v11.7 처음 운영하는 선생님 모드
   - 반별 독립시간, 45분 자동 일시정지, 추가시간, 도움요청, 저장·제출 잠금
   - 기존 평가 문항·배점·답안 검증 구조

운영 권장
- 수업시간에 /guide#guide-teacher로 한 번 전체 설명
- 학생은 개인 기기에서 /guide 확인문제 10개 완료 후 준비 완료 저장
- /operate에서 반별 미완료 학생만 사전 확인
- 실제 수행 중에는 전체 튜토리얼보다 ‘❓ 개념 도움’을 우선 사용
