1. GitHub 무료 가입 → 새 PRIVATE 저장소 만들기
2. 이 폴더 전체를 GitHub 저장소에 업로드
3. Railway 가입/로그인 → New Project → Deploy from GitHub repo
4. Railway 서비스에 Volume 추가 → Mount Path = /data
5. Variables에 TEACHER_PIN=원하는 6자리 숫자 추가
6. Settings → Networking → Generate Domain
7. 학생: https://발급주소.up.railway.app/
8. 교사: https://발급주소.up.railway.app/teacher
9. 교사 PIN은 브라우저에 한 번 입력하면 이후 기억됨
10. AI 키는 배포 후 교사용 화면에서 기존처럼 저장 가능
