2. 문제와 정답 수정 클래스룸용 엑셀·해설 v53

📚 저장된 문제은행
저장된 문제은행을 선택하세요.
📥 엑셀 문제 양식 다운로드
① 불러오기 방식 선택 → ② 아래 버튼 클릭 → ③ 파일 선택 즉시 자동 반영
처음 사용하는 경우: 위의 📥 엑셀 문제 양식 다운로드를 눌러 작성 규칙과 예시가 포함된 템플릿을 사용하세요.
엑셀 양식: A열=문제, B열=정답, C~G열=보기1~보기5, H열=해설(선택). C~G가 비어 있으면 주관식, O/X 두 보기면 OX, 보기 2~5개면 객관식으로 자동 판별합니다. 주관식 복수 정답은 B열에서 |로 구분하세요. H열에 해설을 입력하면 정답 판정 직후 함께 표시됩니다.
※ 버튼을 누르고 파일을 고르면 즉시 자동으로 불러옵니다. 여러 파일도 한 번에 선택할 수 있습니다. 각 파일은 별도의 문제은행으로 저장되며, 첫 번째 워크시트를 읽습니다. .xlsx와 .csv를 지원합니다.

현재 기본 문제: 통합사회2 1단원 50문항 + 해설 50개 · 주관식 17 / 객관식 21 / OX 12 · 정답 판정 뒤 핵심 해설이 표시됩니다.
