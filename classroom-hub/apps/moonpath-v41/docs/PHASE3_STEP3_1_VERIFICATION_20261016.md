## 수정 없이 지켜야 할 개발 보호조건

1. `moonpath-dev/` 운영 코드와 과거 로컬 저장키 사용/초기화 금지.
2. 사용자가 전체 신규 픽셀아트를 확정했으므로, 기존 승인 이미지의 픽셀을 런타임 자산으로 사용하지 않음.
3. 소스 사진에 인쇄된 한글·버튼을 새로운 배경 PNG로 굳히지 않음. 내용·상태·클릭은 HTML/CSS/JS.
4. `PHASE 3-1`은 **참고 원본 검사·규격 정의**이지, 실제 신규 디자인 또는 게임 전체 개발 완료가 아님.
5. 사용자 최종 승인 전 `main` 병합·PR 자동 병합·Railway 배포 금지.
