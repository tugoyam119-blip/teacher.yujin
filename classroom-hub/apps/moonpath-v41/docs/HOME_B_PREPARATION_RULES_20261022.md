# 새로운 탐험 — 준비 화면과 승인된 새 규칙 구현

2026-10-22. 사용자는 첨부 화면의 설정/요약 구성, 실제 기능 추가, 새 규칙표 설계와 구현을 승인했다. 출발 HEAD: 시험 브랜치 `cloudflare-moonpath-v411-test`, `c99ed8bcbda3e58f4b28bdf2abcb7f6958f2d83b`.

## 동작

- 기존 두 단계를 한 화면으로 통합했다. 왼쪽 문제팩·탐험 시간·진행 확인·참여 방식·모둠 수·모둠당 인원·Seed, 오른쪽 실시간 요약과 시작/돌아가기. 슬롯·이름·문제 타이머는 펼침 설정에 둔다. 긴 설정은 왼쪽에서 스크롤한다.
- 새 UI 기본값:45분, 기본 확인, 순환+가로채기,6모둠×4명, 문제60초, 체력8. 구형 엔진 호출의 기본4모둠과 기존 저장은 유지한다.
- 탐험25/45/60분은 현재 차시의 활동 시간만 계산하며 일시정지를 제외한다. 저장 명령마다 알려진 활동 시간을 누적한다. 예기치 않은 종료 이후의 알 수 없는 시간은 추산하지 않으며 복원 시 일시정지한다.
- 시간이 되면 교사가 ‘이번 문항 후 수업 마무리’를 선택한다. 예약은 새 기본/회수 문항을 차단한다. 현재 문항을 자동 종료·채점하지 않으며 진행 중인 문항/가로채기/회수 처리 후 교사가 종료한다. 예약 취소·계속 진행과 새 차시 시작도 가능하다.
- 꼼꼼 확인: 수업 시작·지역 진입·문제 타이머 시작을 분리. 기본 확인: 지역 진입에 수업 시작을 포함, 타이머는 별도. 간편 진행: 지역·첫 문제 시작 클릭으로 수업·지역·첫 출제·첫 타이머를 묶는다. 판정·정정·보관/복원 확인은 생략하지 않는다.
- 페이지 이동은 같은 탭의 일회용 인계 기록을 사용한다. 슬롯·탐험ID·정확한 저장 revision·5초 유효기간을 검사하고 열기 전에 소비한다. 일반 새로고침/복원은 재사용하지 않는다. 이동 지연 시 수동 재개가 필요하다.
- 완전 협동은 모둠/대표 순환과 오답 회수를 유지한다. 가로채기는 UI에서 숨기며 엔진 직접 호출도 거부한다. 순위를 추가하지 않는다.
- 모둠2~8, 모둠당1~10명은 실제 초기 명단(학생1…)으로 생성되어 대표 순환에 쓰인다. 새 탐험의 모둠 선택 기본은 자동 순환이다.
- Seed64자 이내, 공란은 생성ID에서 자동 생성해 저장한다. 같은 Seed·문제팩/버전·규칙·경로/모둠 선택 이력에 같은 출제 순서를 재현한다. 다른 교사 선택의 결과까지 같다고 주장하지 않는다. 저장·백업·복원에 포함한다.
- 기본팩 또는2MiB 이하의 검증된60문항 YQBank JSON을 사용한다. 제목·버전·문항 수 표시와 원본 저장을 유지한다. 예상 총 문항 수를 임의 표시하지 않는다.
- 기존 공동 체력·열쇠·별빛 엔진을 사용한다. 지역 최초 완료 열쇠+1(비소모). 구버전 FINALE 열쇠 소비를 도입하지 않는다.

## 배치와 보존

820×500 및 승인 PNG 유지. 본문(48,116,724,360), 두 열424/284와 간격16. 오른쪽 footer(488,348,284,128): 상태24, 간격8, 버튼44 두 개/간격8. 제목·닫기는 STEP05 안전 영역 유지. 작은 화면은16px과44px 이상 버튼으로 세로 재배치한다.

승인 PNG, HOME 무대 이미지/좌표, 기존 사용자 DB, main, Railway, Cloudflare 배포는 변경하지 않았다. `settings.preparation.version=1`을 가진 새 탐험에만 적용하며 생성 이벤트와 일치를 검증한다. 과거 STEP05 문서는 당시 두 단계 구성의 이력이다.
