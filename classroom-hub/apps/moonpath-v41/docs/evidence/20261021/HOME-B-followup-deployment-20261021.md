## 구현한 기능

- 새 탐험 이름(1~80자), 접이식 고급 제한 시간(45/60/90/120초/끔). 이름은 저장·재열기·JSON에 보존하며 기존 이름 없는 저장과 호환한다.
- 교사용 일지: 차시·누적 출제/정답/오답/교사 판정 대기, 모둠 공헌도, 문항별 현재 유효 판정, 감사 이력, CSV.
- 판정 정정 반영, 자동 채점 권고와 교사 확정 구분, 모둠 순위 정렬 제외, CSV 수식 방어·BOM·인용 처리.
- 작업 중 입력 동결, 닫힌 팝업의 늦은 비동기 응답 표시 방지, 같은 슬롯 선택 유지.
- 승인 PNG·HOME 좌표·기존 HOME 원본·기존 저장 키는 수정하지 않았다.

- 배포 CSV 실제 다운로드 후 문항 IS2-U01-E03·교사 판정 대기·감사 이력·BOM 확인.
