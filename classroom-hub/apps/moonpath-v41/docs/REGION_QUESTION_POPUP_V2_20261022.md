2026-10-22. 사용자 요청은 승인 프레임을 활용한 지역 문제 팝업 개편이며 문항·채점·타이머와 main/Railway/기존 사용자 저장을 보존한다. 출발 로컬 시험 브랜치967e86c(STEP08 검수 기록), 원격c0fa130, 기존 실행 구현15a6b01이다.

## 적용

본문 스크롤+하단 고정, 좌문항/우조작, 문항/교사 조작 분리의3개 안을 비교했다. 긴 지문과7개 문항 형식에 충분한 폭을 주고 추가 전환 없이 조작하는 첫 안을 채택했다.

- 기존 승인 `assets/home/popup-v2/` PNG17종을 그대로 사용한다. 프레임·명판·모서리·모바일 테두리 및 버튼3종×4상태. 새 PNG 제작이나 원본 덮어쓰기는 하지 않는다.
- 논리820×500, 제목(204,36,412,32), 본문(48,108,724,228), 하단(48,348,724,128). 지문·답안 영역만 스크롤하고 상태 메시지24/간격8/타이머44/간격8/판정44를 고정한다.
- 단일 HTML 빌드에 승인 PNG 원본 바이트를 data URI로 포함한다. 원본 대장 SHA-256과 비교한 뒤 임베드하며 포함 자산과 해시를 빌드 대장에 기록한다. 단일 HTML의 이미지 로딩에 외부 파일이 필요하지 않다. 산출물 줄바꿈은LF로 통일해 Git 전송 시 해시가 달라지지 않게 한다.
- 작은 화면은16px 본문과44px 이상 버튼을 유지하고 답안/조작을 세로 재배치한다. 낮은 화면은 본문과 조작 구역을 함께 스크롤한다.
- `question-popup.js`는 표시 전용이다. 기존 문항/입력/버튼 DOM ID와 명령 핸들러를 유지한다. HOME·수업 재개는 팝업 안으로 같은 노드를 옮기고, 문항이 닫히면 기존 도구 모음으로 돌린다. HOME은 원래 일시정지·저장·이동 핸들러를 그대로 호출한다.
- 새로운 문항은 제목으로 초점을 옮기고 본문 스크롤을 초기화한다. 타이머 조작/오류로 재표시할 때는 입력 요소를 다시 생성하지 않아 선택값/서술 답안을 유지한다. 기존 오류 메시지도 팝업 안에서 확인할 수 있다.
- 교사용 시계는 한국어 상태와 기존 ‘저장 기준’ 잔여 시간을 표시한다. 실시간 카운트다운이나 자동 판정을 새로 도입하지 않았다. 교사 판정 근거·정답/오답 확인은 유지한다.
