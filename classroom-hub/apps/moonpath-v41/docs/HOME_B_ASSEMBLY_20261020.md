# HOME B 독립 레이어 조립 및 기능 연결 — 2026-10-20

## 이번 변경

`home-b/`에 회수 원본을 사용하는 960×540 HOME 조립본을 추가했다. 기존 moonpath-dev HOME 이미지·좌표·저장 키는 수정하지 않았다. 기존 설정 팝업에 조립본으로 가는 링크만 추가했다.

원본 출처는 [스프라이트 제작 검수](https://chatgpt.com/c/6ad1bdcc-59a8-83ee-86c8-991895134cff) 대화다. 원본 25개를 실제 이미지 뷰어에서 다운로드했고, 그중 배경 13번·캐릭터 14번·UI 시트 15번·프레임 24/25번을 바이트 변경 없이 신규 자산 경로에 복사했다. 생성 모델은 사용하지 않았다. 승인된 로고·슬로건은 기존 파일을 그대로 연결했으며 원본 SHA-256이 회수 파일과 일치한다.

자산별 크기·SHA·승인 구분·표시 영역은 `data/home-b-assembly-assets.json`에 기록한다. CSS/DOM의 표시 전용 크롭과 양축 동일 배율만 사용한다. UI 시트는 아이콘 영역만 표시하며 시트에 구워진 메뉴 글자는 사용하지 않는다. 메뉴 이름·설명과 클릭 상태는 HTML이다.

로고 `(122,9,244,153)`, 슬로건 `(134,166,232,24)`, 메인 메뉴 `(733,125/203/280/357,208,66/65)`, 보조 메뉴 `(749/812/877,440,48,55)`는 이전 대화의 최신 배치 후보를 계승한다. 캐릭터는 STEP 02 수정 후보 `(105,211,311,263)`를 사용한다. 이번 조립만으로 최종 좌표 승인으로 승격하지 않는다.

## 저장 연결

- 기존 엔진과 `moonpath-v411-phase29-smoke-db-v1` 시험 DB를 재사용한다. 구형 운영 localStorage 및 정상 엔진 DB에 접근하지 않는다.
- 새 탐험은 빈 슬롯만 생성하며, 교사 확인 후 지역 시험 화면으로 이동한다.
- 이어하기는 선택한 시험 슬롯만 연다. URL에서 신규 탐험을 자동 생성하지 않는다.
- 지역 시험의 `HOME으로`는 진행 차시·타이머를 저장 후 정지하고 쓰기 잠금을 해제한다. 실패하면 이동하지 않는다.
- HOME 설정에서 JSON 백업과 같은 번호의 빈 슬롯 복원을 제공한다. 기존 슬롯 삭제·덮어쓰기 기능은 추가하지 않았다.
- 일지·기록은 현재 저장 요약만 제공한다. 상세 일지·PDF·CSV는 구현 완료가 아니다.

## 실제 검증

- 기존 Node 자동 검사 530개 통과, HOME JS 문법 검사 및 지역 시험 HTML 재빌드 완료.
- 실제 브라우저 1280×720: 모든 이미지 정상 로드, 독립 레이어와 메뉴 7개 표시, 오류 로그 없음.
- HOME에서 슬롯 II/4모둠 생성 → 지역 시험 → 문항 IS2-U01-E03 준비 → 타이머 시작 → HOME 복귀 → 이어하기 성공.
- 동일 문항, 60초 저장 기준, 차시 PAUSED / 타이머 PAUSED 복원 확인.
- 기존 슬롯 II에 새 탐험 생성 시도: 거부, 기존 문항 보존.
- HOME JSON 백업 생성. 파일 SHA-256 `18f28e5e213a6d0c98a825c45a92508397ab3b4137d32d1df87b8956b43052e3`.
- 데이터를 삭제하지 않고 별도 로컬 origin의 빈 슬롯 II에 JSON 복원 성공. 이어하기에서 같은 문항·정지 상태·revision 8 확인.
- HOME 일지에서 출제 1문항·모둠 4개·별빛/열쇠 0 요약 확인.

## 남은 승인·미검증

- 배경·캐릭터·프레임·아이콘은 회수한 제작 후보다. 승인 로고·슬로건을 제외한 최종 런타임 자산/전체 HOME 화면 승인을 주장하지 않는다.
- 이미지 뷰어에서 회수한 원본은 로컬 blob 다운로드다. Railway가 다운로드할 지원되는 원격 원본 참조가 없어 이번 신규 PNG의 F5 큐 접수는 수행하지 않는다. 검증된 git 바이너리 전송을 사용하고 원격 전체 SHA를 별도 대조한다. 큐 성공이나 F5 왕복 완료로 표시하지 않는다.
- 960×540은 논리 무대다. 960×540/390×844/1280×800 viewport 변경을 요청했지만 실제 DOM은 세 번 모두 1280×720이었다. 해당 해상도 시험은 통과로 기록하지 않는다.
- Windows Chrome/Edge, 모바일 실기기, file:// 오프라인, 강제 프로세스 종료, 두 창 충돌 시험은 이번 조립에서 미실시.
- 클래스룸 공유 main 병합·원격 배포·배포 후 동일 시험은 별도 상태이며, PR 작성만으로 완료로 표시하지 않는다.
