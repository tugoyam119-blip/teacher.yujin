# 탐험 보관함 (2026-10-21)

> 당시 작업 기록입니다. 이후 병합·개발 링크 검증 및 현재 미완료 범위는 [최신 통합 기록](CURRENT_IMPLEMENTATION_AND_CHANGELOG_20261021.md)과 [당시 배포 증거](evidence/20261021/README.md)를 확인하세요.

사용자 선택안 ②: 기존 탐험을 보관함에 옮겨 활동 슬롯 I~III를 재사용한다.

## 동작
새 탐험/설정/이어하기 → 탐험 보관함. 슬롯·이름 확인 → 보관 확인 → 기록/문제팩/이벤트/최신·직전 체크포인트를 보관하고 슬롯 비우기를 하나의 IndexedDB 트랜잭션으로 처리한다. 영구 삭제 기능 없음.
원래 슬롯이 비어 있을 때 복원한다. 다른 슬롯으로 기록을 무단 재배치하지 않으며 기존 탐험 덮어쓰기 금지. 복원 완료된 보관본도 JSON 백업 가능. 수업·타이머는 저장·일시정지한 상태로 보관한다.
보관함은 이 브라우저/사이트의 IndexedDB에 있으며 클라우드 동기화는 아니다. JSON으로 별도 보관/이관 가능.
DB 버전1→2 추가 저장소만 생성. 기존 저장소/키 유지. 오래된 브라우저 코드가 남지 않도록 HOME·책장 진입 모듈 버전 갱신. 승인 PNG·메뉴 좌표 변경 없음.

## 검증
기존544 + 보관5 자동 검사. 원본 상태/이벤트/체크포인트/선택팩 복원, 보관 실패 롤백, 복원 실패 롤백, 슬롯 점유 차단, 잘못된 작성자/오래된revision/중복ID 차단.
로컬 실제 IndexedDB 버전1 저장 유지→업그레이드→보관해 슬롯I 비움→복원→기존 선택팩 문항 유지→다시 보관→새 탐험 생성→책장 진입 성공.
실서비스 반영과 실제 링크 검증은 승인/배포 후 별도 기록.
