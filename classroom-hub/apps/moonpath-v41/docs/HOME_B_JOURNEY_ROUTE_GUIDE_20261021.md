이전 추가 탐험 배너는 계속하기에서 현재 지역을 열었다. 시작 이벤트 확정 후 지역 진입 쓰기 전에 중단되면 현재 지역은 원래 복귀 위치이므로 잘못된 지역으로 연결됐다. 현재는 추가 탐험 복귀 장부의 대상과 상태를 읽어 AVAILABLE→대상 진입, IN_PROGRESS→이어하기, COMPLETED→복귀로 구분한다. 기존 이벤트·지역 엔진의 검증과 단일 저장 트랜잭션을 그대로 사용한다.

테마 정보 열람/닫기는 로컬 화면 상태만 바꾸며 수업 시작·분기 선택·지역 진입·보상·저장 이벤트를 만들지 않는다. 해금되지 않은 테마에서 갈림길 진입 버튼을 제공하지 않는다. 정보 열람 자체를 별빛을 소비하는 ‘별의 나침반’ 마법 구현으로 기록하지 않는다.
