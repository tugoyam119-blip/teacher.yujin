# HOME B 책장·갈림길 연결 검증 (2026-10-21)

- 기준: MASTER_v4.1.1_original.md. HOME → 새 탐험/이어하기 → 마법 책장 → 갈림길 → 지역.
- 새 탐험은 책장만 저장하고 차시·지역을 자동 시작하지 않는다.
- 책장은 6테마, 왼쪽 파랑/빨강/노랑, 오른쪽 보라/초록/은빛 순서. 이전 테마 마지막 지역 완료 전 다음 테마 잠금.

- 진행 문항/가로채기/회수가 있으면 다른 경로로 이동하지 않고 원 지역 계속하기만 제공한다.
- 저장된 책장/갈림길/지역과 선택 분기, 보상을 유지하며 복원 후 수업/타이머는 자동 재개하지 않는다.

- 자동 검사 540개 통과(기존 535 + 연결/잠금/진행 문항 보호/JSON 복원 5).

- HOME HTML/CSS, 승인 PNG, 배치 manifest, 기존 저장 키는 변경하지 않는다. 새 PNG 생성/업로드 없음.
