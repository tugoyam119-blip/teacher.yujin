# 제작 환경 / 엔진·배포 분리 원칙

- **공통 엔진 하나**에서만 규칙/상태/보상/문항을 구현하고 동일한 버전으로 온라인·오프라인 빌드를 생성.
- 신규 이미지 자산은 PNG 별도 원본. 텍스트, 버튼, 동적 문제와 입력은 HTML/CSS/JS. 기존 PNG는 참고만.
- 온라인: 기존 클래스룸과 별도 신규 앱 경로. 운영 서비스·등록·라우팅 변경 금지(승인 전).
- 오프라인: **외부 요청 없는 한 개의 HTML**로 패키징 예정. `file://` Chrome/Edge 테스트 전 '작동' 주장 금지.
- 저장: `moonpath-v411` 전용 IndexedDB, 이벤트와 상태 트랜잭션, 직전/최신 체크포인트, 독립 3슬롯. 기존 localStorage 키 접근 금지.
- 두 창: 교사용 단독 writer, 학생용 공개 데이터만 읽기 전용. 메시지에 정답/해설/PIN/감사 숨김.
- 질문: 7개 **실제** 원본 유형 모두 지원해야 함. 변환 로직은 `data/YQBank_60_v1.0.0_source.json`을 수정하지 않음.
- 신규 픽셀아트: 960×540 무대; L0~L6; 캐릭터 64×64 + 프레임 4/6/6/4/3; 30개 지역 각자 신규 배경.
- 현 상태: PHASE 0 계약만 기록. 상태머신, IndexedDB, 화면, PNG, 빌더, 배포 출력은 **아직 구현 전**.
