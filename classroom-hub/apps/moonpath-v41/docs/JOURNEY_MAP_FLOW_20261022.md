# 설명 → 지도 → 마법 책장 갈림길 (2026-10-22)

## 최신 사용자 지시와 기존 기준 대조

사용자 확정: 게임 기본 설명 팝업 → 지도 → 처음 시작 지점 클릭 → 마법 책장 형태의 갈림길 선택. 기존 마스터 §3의 HOME→책장→갈림길 흐름에서, 전체 여정의 지도와 기본 설명이 빠진 점을 이번 지시로 보완한다. 책장을 6테마의 단순 버튼 목록으로 표현하지 않고, 지도는 테마 목적지, 펼쳐진 책은 테마 안의 지역 선택으로 역할을 나눈다. 이번 화면 순서는 원문보다 최신 사용자 지시를 우선한다.

마스터 결정03/16/22/33, §2~3과 PHASE3_STEP3_1_REFERENCE_AND_STANDARD_20261016.md를 대조했다. 테마 순차 해금, 지역 ①→②/③→④→⑤, 교사 진입 확인, 미방문 추가 탐험과 복귀, 책장/갈림길/지역 독립 상태는 유지한다. 실제 Y 경로와 책의 선택 영역을 함께 배치한다. 책장색 좌3/우3의 옛 배치는 전체 테마 지도 순서(1→6)로 교체하며, 테마별 색과 이름은 유지한다.

## 구현과 보존

- journey/index.html: 승인 공통 프레임/명판/닫기/버튼 PNG로 설명 dialog. 무대 바깥 native modal로 키보드 포커스와 Escape 지원. 게임 설명에서 재열람 가능.
- journey/map-ui.js: 저장 API 없는 표시 모듈. 6테마 지도/연결 도로, 잠금/현재 위치/완료 및 길 미리보기. 기존 themeUnlocked/regionOptions의 실제 권한을 사용한다. 처음 시작 클릭은 기존 FORK 화면 이벤트만 발행한다.
- 갈림길: 길과 5개의 펼친 책을 코드 기반 SVG/HTML로 표시. 초기에는 입구만 가능하며 좌우 길은 기존 게임 규칙에 따라 해금된다. 지역 미리보기→기존 교사 진입 확인→지역/문제 화면 연결은 유지.
- 설명 확인 여부는 expeditionId별 탭 sessionStorage에만 기록. 원래 게임 저장 스키마·IndexedDB 이름/버전·엔진·진행·문항·보상·명단·HOME 원본은 변경하지 않는다. 기존 지역/문항 이어하기에 설명을 강제로 끼워 넣지 않는다. 지도/책장 이동에는 기존 화면 이동 이벤트가 정상 저장된다.
- 작은 화면은 문서 세로 스크롤. PC 갈림길도 세로 스크롤로 전체 경로와 잠금 사유 열람 가능.

신규 PNG 생성/수정 없음. 승인 PNG 바이트는 그대로 사용했다. 이번 지도/책의 SVG는 기능과 배치를 구현한 것으로, 기준서의 최종 전용 픽셀아트 및 후면 캐릭터까지 승인 완료됐다고 표시하지 않는다. 후면 캐릭터·최종 지형 그림은 미완료다. 기존 PNG를 새 승인 자산으로 승격하지 않았다.
