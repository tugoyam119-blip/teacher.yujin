# 공동 체력·책장 복귀 규칙 (2026-10-21)

사용자 최신 명시 지시: 체력 추가, 공동체력8/기본 오답−1/유효 회수+1(최대8), 체력0일 때 ‘책장으로 복귀·체력 회복, 기존 지역 진행 보존’ 선택. 기존 기준서의 체력 미도입 상태를 이 범위에서 갱신한다. 열쇠·별빛·보상 및 기존42결정의 나머지는 유지한다.

## 확정 동작

- HOME에서 새로 만든 탐험만 공동 체력8로 시작한다. 기존 저장에는 자동 적용하지 않는다. 별빛·열쇠와 독립적이다.
- 기본 문제의 교사 확정 오답마다1 차감. 시간 초과·무효 종료 자체는 차감하지 않는다. 가로채기·회수 실패로 같은 문제를 이중 차감하지 않는다.
- 유효한 회수 성공은 문항별1회만 +1, 최대8. 판정 정정 시 현재 유효 판정으로 재계산한다.
- 0이 되면 소진 상태를 유지한다. 새 기본 문제·새 회수 호출·지역 진입/완료/추가탐험 이동을 막되, 현재 가로채기·회수는 마무리할 수 있다. 소진 뒤 미션 마무리의 회복분으로 복귀를 우회하지 않는다.
- 문항·미션이 끝난 뒤 교사가 ‘책장 복귀·체력8로 회복 확인’을 누르면 한 이벤트/저장 트랜잭션으로 책장 이동·체력8·차시 일시정지를 확정한다. 저장 실패 시 회복 성공 표시 금지.
- 진행 지역·이미 푼 문항·오답 회수·주경로·열쇠·별빛·추가탐험 복귀 위치를 초기화하지 않는다. 복귀 후 남은 진행을 이어가며 타이머/수업은 수동 재개한다.
- 소진 오답을 정답으로 정정해 더 이상 소진 조건이 없으면 복귀 요구도 해제한다. 이미 실행한 복귀 이벤트는 감사 이력으로 보존하며 정정 때문에 과거 화면 이동을 되돌리지 않는다.

## 구현·호환

src/world/health.js에서 원래 판정 이벤트 순서와 현재 유효 판정/회수 결과로 재계산한다. 복귀는 HEALTH_RETURNED, 중복 eventId는 기존 엔진에서 멱등 처리한다. 체력 값과 원장 불일치는 저장·복원 검증에서 거절한다.

새 체력 탐험은 settings.healthEnabled=true 및 상태/백업 schemaVersion2를 사용한다. 이전 탐험은 schemaVersion1 그대로다. 새 엔진은 둘 다 지원하고 구엔진은2를 거절하므로, 오래 열린 창이 체력을 모른 채 새 탐험을 덮어쓰는 것을 방지한다. DB 이름·스키마 버전과 저장 키는 바꾸지 않는다. 새 백업은 구버전 앱으로 복원할 수 없고 이번 버전 이후를 사용해야 한다.

엔진 API create({healthEnabled:true})로 명시 활성화하며 HOME 생성 경로에서 이를 사용한다. 시험용 기존 엔진 호출은 기본false로 호환한다. 책장·갈림길과 지역 상태, 학생 공개 투영에 체력 숫자만 표시한다. 정답/비공개 감사 자료는 공개하지 않는다. 새 이미지 생성 없음, 승인 HOME 자산·좌표 변경 없음.
