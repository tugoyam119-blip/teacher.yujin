## 구현

- 820×500 논리 규격과 460:248 본문(간격16), 제목판 없는 중앙 제목, 원형 닫기 버튼. 원본 PNG4개를 신규 경로에 바이트 그대로 보존하고 Canvas2배 backing에서 표시 크롭·슬라이스만 적용한다. 제목·X·입력·버튼 글자는 HTML/CSS다.
- 수업 구성/진행 방법/저장 정보는 같은290px 스크롤 영역에 항상 존재한다. 상단 버튼은 위치 이동이며 페이지·탭 전환이 아니다. 마지막 입력 아래 여유와 하단 위치 안내를 유지한다.
- 요약200px, 상태48px, 시작44px, 돌아가기44px와 간격8px를 분리한다. 제목(204,48,412,32), 닫기 클릭(728,33,64,64), 요약(524,116,248,200), 상태(524,324,248,48), 시작y380, 돌아가기y432.
- 기존 문제팩 검증 엔진과 TeacherEngineSession 생성/슬롯 쓰기 보호를 사용한다. 기본팩/JSON60문항/2MiB 검증, 인원·활동시간·진행 확인·참여·타이머·Seed를 실제 생성 설정으로 연결했다. 임의로 기존 슬롯에 덮어쓰지 않는다.
- 문제팩의 실제 제목·검증 결과를 사용한다. 가져온 긴 제목은 말줄임과 전체 제목 툴팁으로 제공하며 HTML로 삽입하지 않는다. 기본팩으로 다시 선택 가능하다.
- 오류 시 오른쪽 확인 버튼이 해당 묶음으로 이동하고 입력에 초점을 둔다. 빈 이름·미검증 팩은 시작해도 저장하지 않는다. 저장 실패는 같은 상태 영역에 표시한다. 닫기/돌아가기/Escape와 기존 busy 차단·HOME 포커스 복원은 유지한다.
- 전용CSS는 `.preparation`에만 적용한다. 기존 v3 규칙만 제거하고 다른 팝업 규칙은 유지한다. 폰트는 승인 시안과 같은 NotoSansKR의 전체 글리프를 WOFF로 담아 임의 이름/문제팩 제목을 지원한다.
- 화면은 1배 논리 크기를 유지하며 좁거나 낮은 화면은 팝업 전체 스크롤로 접근한다. 모바일 전용 재배치나 실기기 승인을 의미하지 않는다.
