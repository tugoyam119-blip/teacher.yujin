# 새 생성 PNG 전체 경로 시험 — 2026-10-21

상태: 원본 생성·검사·GitHub 전송 및 전체 재다운로드 PASS. PR #58은 사용자 명시 승인 후 main에 병합됐다. 공유 개발 서비스 배포는 Railway QUEUED 상태로 대기 중이다. 실제 개발 도메인 브라우저 확인은 아직 미실시다. 전체 경로 성공으로 선언하지 않는다.

## 실제 수행

1. 내장 image_gen에서 새 투명 PNG를 생성했다. 프롬프트는 별도 시험용 혜성 유리병 일러스트이며 HOME 이미지를 입력하거나 수정하지 않았다. 정확한 프롬프트는 시험 경로 manifest.json에 보존했다.
2. 생성 결과의 실제 로컬 PNG를 작업 경로에 복사했다. 원본은 보존했다. PNG 디코드·알파·규격·전체 SHA-256을 검사했다. 리사이즈나 색/알파 변경 없이 CSS contain으로 표시한다.
3. 테스트 브랜치에 Git 바이너리로 전송하고 GitHub raw에서 전체 파일을 다시 내려받아 원본 크기·SHA-256 일치를 확인했다.
4. 로컬 브라우저 시도는 127.0.0.1 연결 시간 초과였다. 로컬 화면 PASS로 기록하지 않는다.
5. 별도 시험 페이지를 준비했다. 페이지는 fetch한 PNG의 SHA-256·크기와 실제 img 규격을 대조한다. 저장소 접근 코드나 HOME에서 이 페이지를 호출하는 코드는 추가하지 않았다.
