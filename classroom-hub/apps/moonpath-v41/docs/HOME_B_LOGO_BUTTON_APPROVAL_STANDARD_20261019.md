# HOME B 로고·슬로건 승인 및 버튼 공통 프레임 제작 기준 (2026-10-19)

## 승인·보존 범위
- HOME B 디자인 방향은 유지. 논리 무대 960×540, contain, 배경·캐릭터·UI 분리.
- 사용자 승인: 메인 로고(문구 `미지의 길`, 부제 `달빛 마도 탐험`, 금빛 초승달·별 장식)를 **글자+장식 하나의 PNG**로 사용.
- 사용자 승인: `문제를 넘어, 더 넓은 세상으로`는 얇고 간결한 글자·별 장식이 포함된 **별도 PNG**로 사용.
- 예외 규칙: 로고/슬로건은 통합 이미지. 그 외 버튼·팝업 등 동적 UI는 **프레임 PNG + 아이콘 PNG + HTML 텍스트**, 클릭·선택·비활성은 HTML/CSS/JS.
- 기존 디자인 승인과 런타임 최종 자산 승인·브라우저 QA는 별개.

## 버튼 공통 프레임 개발 현황
- 메인 가로형 1종과 보조 정사각/세로형 1종 **후보 이미지 생성**됨. 아직 사용자 승인 및 실제 목표 규격/알파/외곽/HTML 결합 검증 없음.
- 아이콘 7종(나침반, 열린 책, 일지, 톱니, 트로피, 도움말, 나가기)을 각기 투명 PNG로 만들고 HTML 텍스트와 결합한다.
- 최종 기본 메뉴는 `새로운 탐험 / 이어하기 / 탐험 일지 / 설정`. 시안의 `마법 책장` 텍스트를 별도 확정 메뉴로 취급하지 않음.
