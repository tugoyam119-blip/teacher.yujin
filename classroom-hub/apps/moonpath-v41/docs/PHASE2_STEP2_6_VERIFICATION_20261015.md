## 1. 실제 구현 범위

| 기능 | 적용된 동작 | 통과 범위/제약 |

| 별빛 부족 및 정산 | 소비에 별빛이 부족하면 거부, `settlementRequired=true`이면 모든 별빛 소비 차단, 모둠 공헌도는 차감하지 않음 | Node PASS |

### 마법 5종 범위의 미완료 부분

- **달빛의 속삭임(T1):** 출제 문제당 1회, 소비/사용 기록 구현. **실제 학습 힌트 문장 생성·노출 UI는 미구현**. 정답 구매/자동 공개 없음.
- **별의 나침반(T1):** 현재 지역의 정보 조회 비용/한도 기록 구현. 실제 길 정보 UI·이동은 후속 단계.
- **기억의 수정(T2):** 유효한 미회수 대상에 대한 비용/한도 기록 구현. 실제 단서 텍스트·테마 해금은 후속 단계.
- **시간의 모래(T3):** 공식 타이머를 +20초 연장하는 계산 및 지출 원자성 구현. 실제 브라우저 타이머 1초 경계 실증 미완료.
- **숨겨진 별의 눈(T4):** 현재 지역의 추가 탐색 사용 비용/한도 기록만 구현. **실제 추가 탐색 사건/화면 해금은 아직 구현하지 않음**.
- 결정 09의 **‘단계별 해금’**은 유효하지만, T2~T4를 **정확히 어느 테마·지역 완료 시 해금하는지** 마스터에 명시되어 있지 않아 임의로 수치를 설정하거나 ‘실제 해금 완료’로 보고하지 않음. 2-8 지역 진행 및 사용자 승인 후 해금 조건·이벤트를 완성해야 함.

## 3. 실제 검사·통과 증거

- **환경:** Linux, Node.js `v22.16.0`; `npm test` 즉 `node --test tests/*.test.mjs`.
- **누적 Node+모의 IndexedDB:** 기존 PHASE 0~2-5 **350건 PASS** + 신규 2-6 **52건 PASS** = **402건 PASS / 0 FAIL**.
- **핵심 체크:** `npm run check:syntax` 검사 통과, 공식 60문항 SHA-256 `3a2401498a73bf5afd7ed72329ef07d4dd742d58f5ab27ab966841cc67c5de7f` 불변.
- **브라우저 시험:** `/usr/bin/chromium`의 `file://` 진입부터 `net::ERR_BLOCKED_BY_ADMINISTRATOR`. **네이티브 IndexedDB 저장 자체는 실행하지 못함(BLOCKED)**. Windows Chrome/Edge 실기기 `file://`, 두 창, 강제 종료 복원은 `NOT_RUN`.
- **마법 테스트에서 잠금 마법을 임시 해금한 것은 단위 테스트용 준비 데이터**이며 실제 월드 해금 이벤트 성공의 증거가 아님.
