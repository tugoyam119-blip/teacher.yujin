# 새 탐험 규칙·문제팩 선택 복구 (2026-10-21)

> 당시 작업 기록입니다. 이후 병합·개발 링크 검증 및 현재 미완료 범위는 [최신 통합 기록](CURRENT_IMPLEMENTATION_AND_CHANGELOG_20261021.md)과 [당시 배포 증거](evidence/20261021/README.md)를 확인하세요.

사용자 지적: HOME B 새로운 탐험에 규칙과 문제팩 선택이 빠짐.

## 변경
HOME → 규칙(v4.1.1 기본 규칙)·문제팩(기본 60문항/JSON 불러오기) 선택·검증 → 슬롯·이름·모둠 수·고급 제한 시간 → 시작 → 책장 → 갈림길.
규칙/문제팩 미선택 시 다음 진행 차단. 아직 지원하지 않는 구버전 감독 강도/시간 프리셋 등을 동작하는 선택지처럼 복원하지 않음.
JSON은 현재 엔진이 검증하는 60문항 YQBank 구조, 2MiB 이하. 잘못된 팩은 시작하지 않음. 선택한 원문을 questions.sourcePack에 함께 저장하여 실제 출제/복원에서 기본팩으로 바뀌지 않게 함. 기존 저장은 이 필드 없이 기존 기본팩으로 호환.
HOME 그림·버튼 좌표 불변. CSS 변경은 새 탐험 선택 팝업 내부에만 적용. 이미지 생성 없음.

## 검증
자동 검사 544개 통과. 추가4개: 선택팩 실제 출제/다른 팩 거절, JSON복원, 잘못된 팩 생성 차단, 이전 저장 기본팩 호환.
로컬 브라우저: 규칙 미선택 차단, 기본팩 검증, 별도 JSON 선택(SETUP-BROWSER-TEST/v1.0.1), 슬롯 설정→책장→갈림길→지역→[선택팩] 접두어가 있는 실제 문항 출제 확인.
실서비스 반영/검증은 병합·배포 후 별도 기록. 신규 규칙은 v4.1.1 기본 규칙 1종이며, 추가 규칙 프리셋을 구현했다고 주장하지 않음.
