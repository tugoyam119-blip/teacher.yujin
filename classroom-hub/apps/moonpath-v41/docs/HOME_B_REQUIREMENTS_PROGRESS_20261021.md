## 집계·저장 원칙

- 원본 답안의 자동 채점 권고는 교사 확정 정답으로 집계하지 않는다.
- 기존 정정 엔진의 effectiveOriginDecision을 사용해 현재 유효 판정을 집계한다. 원본 활동 로그를 수정하지 않는다.
- 모둠은 저장된 순서로 표시하고 공헌도 순위로 정렬하지 않는다. 이 일지는 교사용이며 학생 공개 화면에 연결하지 않았다.
- 활동 시간은 마지막 저장까지의 activeMs를 사용한다. 닫힌 동안 흐른 시간을 추측해 가산하지 않는다.
- 화면에는 최근 문항 200개/감사 100개를 표시하며 CSV에는 전체 목록을 포함한다.
- CSV는 UTF-8 BOM, 셀 인용·쉼표/줄바꿈 처리 및 수식 실행 방어를 적용한다.
- expeditionName은 새 저장의 선택적 메타데이터다. 이름이 없는 기존 백업은 그대로 열며 이름을 기존 슬롯에 강제로 덧쓰지 않는다.

## 실제 확인한 결과

- Node 자동 검사 535개 통과. 이름 제한/기존 저장 호환, 세션 생성→재열기→JSON 무결성 확인, 판정 정정 집계, 자동 권고 제외, 원본 상태 무변경, CSV 수식 방어, 무효 회수 제외를 검사했다.
- 빈 로컬 시험 origin에서 ‘우리 반 달빛 탐험’·3모둠·45초 생성. 지역 기본 목표 3건과 실제 문항 PREPARED/45초 확인.
- HOME 복귀 후 슬롯 이름 표시, 차시 PAUSED, 출제1/정답0/오답0/판정대기1, 모둠3개 일지 표시.
- 일지 CSV 실제 다운로드: BOM·이름·교사 판정 대기 기록 포함 확인.
- JSON 실제 다운로드 후 verifyBackup 통과: 이름·45초·3모둠·revision7 일치.
- 최종 배포 URL의 실제 검사 결과는 사용자 전달 검증 기록에 별도 기록한다. 로컬 결과를 배포 검증으로 대신 표시하지 않는다.

이번 범위에 새 PNG는 없어 F5 업로드를 실행하지 않는다. 모든 V01~V22 또는 HOME 최종 완료를 일괄 PASS로 처리하지 않는다.
