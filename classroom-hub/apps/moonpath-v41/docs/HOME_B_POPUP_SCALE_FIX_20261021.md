# HOME 팝업 크기·가독성 보완 (2026-10-21)

사용자 첨부 화면의 이어하기/새 탐험 팝업이 작다는 지시를 반영했다. PR #60은 이미 병합·배포된 책장 작업이므로 이번 변경과 분리한다.

## 찾아 대조한 이전 구현

보존된 `classroom-hub/apps/moonpath-dev/index.html`의 V4.1 shared fantasy popup을 직접 확인했다. #game-popup은 left7.2%/top3.5%/width85.6%/height92.5%로 화면 대부분을 사용했다. 동적 내용과 프레임을 분리한 기존 제작 규칙도 함께 확인했다. 이 파일과 그 안의 원본 프레임 이미지는 수정하지 않았다.

현재 HOME B의 native dialog는 폭650px·최대높이470px 고정이었으며, top-layer에서는 HOME stage의 CSS transform을 따라 커지지 않아 큰 화면에서 팝업과 글자가 상대적으로 작았다.

## 반영

- HOME 팝업은 960×540 기준820×500으로 화면 배율을 따로 적용한다. 이전 팝업의 폭85.6%/높이92.5%에 가까운 구성이다. 실제 viewport 여백24px 제한으로 화면 밖 유출을 막는다.
- 820×440 제한은 중앙 문제 팝업 기준이며, 이번 변경은 HOME의 규칙/슬롯/일지/설정 대화상자다. 출제 화면은 변경하지 않았다.
- 제목·닫기 버튼을 고정하고 본문만 스크롤한다. 패널 전환 시 본문 scrollTop은0으로 초기화한다. 글자·입력·버튼·슬롯 설명도 배율에 맞춰 확대한다.
- 규칙/문제팩은 넓은 화면에서 두 열, 폭800 이하에서는 세로 배치. 파일 가져오기는 JSON 팩을 선택할 때만 표시한다.
- 폭600 이하에서는 HOME stage와 독립된 화면 대부분 크기의 대화상자와16px 본문·세로 슬롯을 사용하도록 CSS 대응했다. 실제 모바일 시험은 아직 하지 않았다.
- 기존 HOME 이미지·메뉴 좌표·아이콘·저장 키·게임 상태/규칙은 변경하지 않는다. 새 이미지 생성/전송 없음.

## 실제 확인

내장 브라우저 localhost:8777의1280×720에서 새 탐험/규칙·기본팩 선택/다음 탐험 설정/닫기/이어하기를 확인했다. 팝업1093.33×666.66, 기본 본문21.33px. 초기 규칙·팩 화면 본문 clientHeight와scrollHeight가 모두543px로 내부 스크롤 없이 전체 내용·다음 버튼을 표시했다. 이어하기도 같은 크기이며 제목/닫기 버튼이 유지된다. 긴 고급 설정·일지 등은 본문 스크롤을 사용한다.
