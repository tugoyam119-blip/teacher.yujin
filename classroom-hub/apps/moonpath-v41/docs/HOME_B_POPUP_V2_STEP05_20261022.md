# HOME 공통 팝업 v2.0 — STEP 05 구현

2026-10-22 KST. 출발 시험 브랜치 `cloudflare-moonpath-v411-test`, HEAD `d4b4f8656e2b1813bc758f3c6c7615ad9a32e04d`.

## 승인과 범위

현재 대화에서 사용자가 STEP03 프레임 v02와 STEP04 버튼 3종/4상태를 시각적으로 채택하고 STEP05 구현을 지시했다. 이는 전체 게임 출시 승인이나 운영 배포 승인이 아니다. main·Railway·Cloudflare 배포는 수행하지 않는다.

## 구현

- `home-b/index.html`: native dialog를 변환된 HOME 무대 밖으로 이동. 프레임/명판/닫기 장식, HTML 제목, 본문, 상태 메시지와 공통 footer를 분리했다.
- `home-b/popup-ui.js`: 표시 레이어만 담당한다. 저장 API를 호출하지 않는다. 진입/복귀 포커스, footer 분리, 짧은 표시 문구와 전체 접근성 이름, 작은 화면 전환, 상태 이미지 준비를 담당한다.
- `home-b/home-b.js`: 기존 `openPanel()`과 게임 콜백을 유지하고 공통 표시 함수를 연결한다. 슬롯·저장 키·DB 스키마·새 탐험·백업·보관/복원·팩 검증 코드는 변경하지 않는다.
- `home-b/home-b.css`: CSS 장식 v1을 제거했다. 승인 PNG의 프레임과 12개 버튼 상태를 사용하고, 폼과 상태는 HTML/CSS로 표시한다.
- `assets/home/popup-v2/`: 승인 원본은 기존 파일을 덮지 않고 신규 경로에 둔다. 원본 프레임 전체도 `frame-approved-master.png`로 보존한다. 파생/실행 파일은 `data/home-popup-v2-assets.json`에서 구분한다.

논리 크기820×500, HOME 내 중앙(70,20), 제목 안전(204,36,412,32), 본문 viewport(48,116,724,252), footer 메시지(48,396,724,24), 버튼 y432/h44를 사용한다. 본문 viewport에는 스크롤바 예약 영역을 포함하며 텍스트 안전 폭708을 목표로 한다. 브라우저별 스크롤바 폭은 실제 환경에 따라 다르다.

실제 승인 그림의 닫기 원형은 (788,48) 중심이었다. 원본 그림을 훼손하지 않고 desktop HTML 클릭 영역을 (756,16,64,64)로 정렬했다. STEP02의48px보다 넓어진 클릭 영역이며 제목/본문과 겹치지 않는다. 모바일은48×48을 유지한다. 모바일 닫기 배경과 외곽 rim은 승인 프레임에서 크롭한 표시 파생본이며 별도 해시로 기록했다.

작은 화면에서는 배율을1 미만으로 축소하지 않고 본문16px·44px 버튼을 유지한다. 세로 화면은 본문만 스크롤하며 하단 주요/보조/취소를 세로 배치한다. 높이500 미만은 콘텐츠와 footer를 함께 스크롤하며 닫기는 유지한다. 제목과 버튼 모서리는 slice로 유지하고 빈 중간 면을 늘린다.

- 기존 자동 검사560개와 추가 PNG 무결성/승인 원본 보존 검사2개, 총562개 통과.
- 분리된 로컬 Playwright WebKit 브라우저에서7개 메뉴 열기, 공통 footer, Escape/닫기, HOME 실행 버튼 포커스 복귀를 확인했다.
- 규칙/문제팩 미선택 오류가 footer에 표시되고, 기본팩 검증→탐험 설정으로 진행하며 모둠 수 입력이 본문에 남는 것을 확인했다.

-844×390에서 짧은 가로 화면 분기와 통합 스크롤을 확인했다.
- 팝업 조작 전후 HOME DOM·이미지 경로·좌표 불변, 브라우저 pageerror 및 HTTP400 이상 응답0을 확인했다. 키보드 포커스 테두리는 정상적인 상태 변화라 픽셀 동일성 비교에서 제외했다.

증거는 `docs/evidence/20261022-popup-v2/`에 둔다. 실제 사용자 데이터가 없는 독립 로컬 origin과 임시 브라우저 문맥만 사용했다. 운영/시험 도메인의 사용자 DB에는 접근하지 않았다.

재현용 브라우저 검사: Playwright와 WebKit 엔진을 준비하고 `node tests/browser/home-popup-v2-smoke.cjs`를 실행한다. 번들 설치 경로는 `PLAYWRIGHT_MODULE`, 엔진 경로는 `PLAYWRIGHT_BROWSERS_PATH`, 증거 저장 위치는 `POPUP_TEST_OUTPUT`으로 지정할 수 있다. 서버는127.0.0.1의 임시 포트에만 열리며 종료 시 닫힌다.

## 미검증 및 전송

내장 브라우저의 localhost 연결은 타임아웃으로 실패했다. 위 실검증은 별도 로컬 WebKit 엔진이며 Windows Chrome/Edge·모바일 실기기·가상 키보드 실동작 검증이 아니다. 실제 저장 생성/백업/보관 복원 전 과정, 오프라인 단일 HTML, 배포 후 검증은 이번 STEP05에서 수행하지 않았다. 기존 자동 저장 검사와 구분한다.

로컬 원본 PNG를 확보했으므로 `IMAGEGEN_PIPELINE_PROBE_20261021.md` 및 F5 현행 정정에 따른 Git 바이너리 경로를 사용한다. F5 큐 성공으로 기록하지 않는다. GitHub 재다운로드 SHA 대조는 별도 증거로 기록하며 Cloudflare 시험 배포는 STEP07 작업이다.
