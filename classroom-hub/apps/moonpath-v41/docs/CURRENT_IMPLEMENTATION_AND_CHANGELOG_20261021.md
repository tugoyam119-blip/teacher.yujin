## 현재 진입 흐름

클래스룸 개발용 주소는 https://magnificent-gentleness-production-61b8.up.railway.app/apps/moonpath-dev/ 이다. 이 주소는 캐시하지 않는 302 응답으로 `/apps/moonpath-v41/home-b/`를 연다. 기존 HOME은 `/apps/moonpath-dev/index.html`에 보존한다. 클래스룸 카드 자체의 클릭은 교사 PIN 때문에 미검증이며, 개발용 주소 직접 진입은 검증했다.

새로운 탐험 → 규칙·문제팩 선택 → 빈 슬롯·탐험 이름·팀·제한 시간 → 마법 책장 → 갈림길 → 지역 정보 → 교사 진입 확인 순서다. 이어하기는 저장한 화면과 진행 중 문항을 복원하며 수업·타이머를 자동 재개하지 않는다. 규칙은 현재 v4.1.1만 제공한다. 기본 60문항 또는 검증한 JSON 팩을 사용한다. JSON 상한 2MiB, 7종 형식·60문항 검증과 ID/버전 일치를 적용하고 원본을 `questions.sourcePack`에 보존한다. 이전 저장은 기본 팩으로 호환한다.

탐험 이름 1~80자, 팀 2~8개(기본 4), 제한 시간 45/60/90/120초 또는 무제한(기본 60초). 상세 일지와 CSV는 세션·유효 판정·기여·시도·감사 기록을 제공한다. CSV는 BOM·문자 이스케이프·수식 방어를 적용한다.

## 저장을 보존한 방법

IndexedDB 이름 `moonpath-v411-phase29-smoke-db-v1`은 유지하고 스키마 버전만 1→2로 올려 `archives`를 추가했다. 보관은 원본 팩·이벤트·최신/이전 체크포인트를 복사하고 슬롯을 비우는 단일 트랜잭션이다. 쓰기 임대와 revision을 확인하고, 진행 중 수업은 안전하게 일시 정지한다. 복원은 원래 슬롯이 비었을 때만 가능하며 ID를 임의 이동하지 않는다. 복원 완료 표식과 보관본은 남겨 JSON 내보내기를 지원한다. 영구 삭제 기능은 추가하지 않았다. 강제 새로고침 직후 약 30초 쓰기 임대 대기가 발생할 수 있다.

## 승인 자산·좌표·처리 방법

원본 출처는 이전 ‘스프라이트 제작 검수’ 대화에서 회수한 자산이다. 원본 경로·전체 SHA-256·크기는 [조립 자산 대장](../data/home-b-assembly-assets.json), 아이콘 원본 사각형·결과 해시는 [알파 처리 대장](../assets/home/icons-alpha-v1/manifest.json)에 둔다. 로고/슬로건 승인과 조립 후보 전체의 최종 출시 승인을 혼동하지 않는다. `asset-manifest.json`의 최종 승인 배열이 빈 것은 개발 화면 미구현이라는 뜻이 아니다.

| 요소 | x,y,width,height (960×540) |
|---|---|
| 로고 | 122,9,244,153 |
| 슬로건 | 134,166,232,24 |
| 캐릭터 | 105,211,311,263 |
| 주 메뉴 | x733,w208; y125,h66 / y203,h65 / y280,h65 / y357,h65 |
| 하단 메뉴 | x749/812/877,y440,w48,h55 |

주 아이콘은 버튼 내부 13,13,40,40, 하단 아이콘은 12,8,24,24를 유지한다. 로고는 원본 비율을 유지해 표시한다. #55에서는 7개 원본 아이콘의 RGB와 크기를 그대로 두고 알파 마스크만 수정했다. 원본 UI 시트와 원본 파일도 보존했다. 생성 도구의 후보는 모양·크기가 달라 폐기했고 게임에 적용하지 않았다. 실제 적용본은 원본 RGB에 밝은 색상 마스크·1px 경계 보호 및 나침반/트로피 보정 마스크를 적용한 것이다. 신규 승인 HOME 그림을 재생성한 것으로 기록하지 않는다.

F5는 건강 상태 확인만 성공했다. 당시 큐가 `.oaiusercontent.com` 원본만 허용하여 GitHub raw 입력은 `INVALID_JOB`으로 거절됐다. 성공한 PNG 전송 작업은 없다. 허용 목록을 넓히지 않고 작업 변수를 정리했다. 실제 아이콘은 Git 바이너리 업로드 후 원격·배포본 7개 전체 SHA-256 일치로 검증했다. [F5 규칙의 현행 제한](F5_ASSET_PROCESSING_RULES_20261020.md)을 함께 따른다.

## 실제 확인과 남은 검증

개발 주소에서 HOME B 진입, 이어하기, 책장/갈림길 상태·잠금 사유·미리보기 취소를 확인했다. #56 슬롯I 백업 비교에서는 기존 질문·시도·팀·회수·보상·지역 상태와 기존 이벤트 접두부가 유지되고 화면 열기 이벤트 2건만 추가됐다. 슬롯II 진행 문항·선택 답·일시 정지 시간이 유지됐다. #54 운영 보관→복원 비교의 변화는 정상적인 중단 복구 이벤트 1건과 revision 증가였다. 이는 당시 시험 결과이며 현재 사용자 슬롯 상태를 보장하는 문장이 아니다.

로컬에서는 시험 JSON을 실제 가져오기로 복원해 주경로4/5·회수1 표시, 완료 결과, 추가 탐험 완료 후 책장 이동·T2-R1 복귀·5/5 완전 탐색을 확인했다. 이 시험 데이터를 실제 사용자 슬롯에 넣지 않았다. 자동 검사를 실제 브라우저 전 과정 검사로 대체해 주장하지 않는다.

남은 작업: 책장/갈림길 최종 승인 그림·캐릭터 자세, 지역 핵심/추가 탐색 사건·단서·연출, 6테마 완주·엔딩, 교사 PIN/학생 읽기 전용 화면의 전체 통합, 명단 가져오기·고위험 설정 적용 정책·PDF/수업 종료 요약, 오프라인 단일 HTML과 file:// 저장/통신/내보내기, Chrome/Edge/모바일·다중 창·강제 종료 실검증. 기존 신규 그래픽 원칙은 개발 후보 사용만으로 일괄 폐기되지 않았다.
