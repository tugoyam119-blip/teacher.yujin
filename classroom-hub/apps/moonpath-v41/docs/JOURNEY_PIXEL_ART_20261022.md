## 구현과 기능 보존

설명→지도→시작→책장 갈림길→지역 정보/교사 확인→지역 문제 흐름 유지. 기존 map-ui.js의 임시 SVG 지형·책을 새 PNG로 교체하고 별도 pixel-style.css에서 조립했다. 지도에서는 저장된 현재 테마 위치, 갈림길에서는 현재 지역 또는 첫 진입 가능 지역을 기준으로 마도사를 표시한다. 자유 이동/게임 이벤트를 새로 만들지 않는다. 장식과 마도사는 pointer-events:none으로 선택을 가로막지 않는다.

지도/책/마도사 그림에 지역 이름·잠금·진행·버튼 기능을 인쇄하지 않았다. 실제 이름/숫자/잠김/현재 위치/완료/추가 탐험 안내는 기존 엔진 상태를 읽는 HTML이다. 이미지의 비율을 지키는 PC 화면을 넓히고 문서 스크롤로 전체 장면을 볼 수 있도록 했다. 모바일 지도는 전체 지형 위에 미리보기를 제공하고 선택 목록을2열로 배치한다. 모바일 갈림길은 전체 서고 지형을 위에 보여 주고5개 책 선택을 세로로 배치한다. 960×540 고정 배율 대신 반응형 레이아웃을 사용하므로 기존 고정 마스터 해상도와 달라진 개발 UI 예외다. 그림 원본 해상도/비율과 게임 엔진 논리는 유지한다.

변경 범위는 journey 표시 파일, 신규 자산/대장/테스트/문서다. src/engine·storage·questions·HOME·원본 승인 PNG·IndexedDB 스키마·데이터 마이그레이션 변경 없음. main·Railway 조작 없음. 기존 모드 CAREFUL/STANDARD/QUICK의 실제 수업/타이머 규칙은 원래 코드가 처리한다. 운영 사용자 브라우저의 DB/프로필에 테스트 데이터를 넣지 않는다.
