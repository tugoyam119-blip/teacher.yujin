# Moonpath v4.1.1 작업 지침
이 경로의 게임 개발·자료 처리 작업을 시작할 때 다음 문서를 먼저 읽는다.
- docs/MASTER_v4.1.1_original.md
- docs/CURRENT_IMPLEMENTATION_AND_CHANGELOG_20261021.md
- docs/F5_ASSET_PROCESSING_RULES_20261020.md
- 최신 디자인 승인 문서와 data/asset-manifest.json

사용자가 승인 범위 안에서 PNG 제작·수정·적용을 요청하면, 별도 “F5로 처리” 재지시 없이 위 F5 규칙을 기본으로 실행한다. 지원되는 원본 파일 참조 → 검증된 Railway 영구 큐 → 테스트 브랜치 → 전체 SHA/크기 대조 → 필요한 게임 연결·브라우저 검증을 진행한다. 전송 성공과 디자인 승인·게임 완성은 별개다.

F5 허용 쓰기 범위는 test/ 브랜치, tools/png-transport-lab/ 아래 PNG다. 게임 자산 경로에 자동 쓰기가 허용됐다고 가정하지 않는다. GitHub 브랜치 간 바이트 전달과 온라인·오프라인 포함 여부를 별도로 확인한다. PNG 외 형식은 지원되는 별도 경로를 사용한다.

원본·승인 디자인·기존 학생 데이터·운영 main·moonpath-dev를 보호한다. 현재 개발 브랜치의 문서/코드 변경은 사용자 지시 범위에서 수행하고, 최종 승인 없이 운영 병합/배포하지 않는다. F5 test 서비스의 승인된 전송 작업 접수·재배포는 가능하다.

토큰·서명 URL·원본 Base64를 로그·채팅·저장소에 출력하지 않는다. 토큰 값을 요구하거나 재발급하지 않는다. 현재 접수 방식의 재배포 필요성과 ImageGen 상시 트리거 부재를 숨기지 않는다.

원본 확보·큐 완료·원격 바이트 일치·게임 경로 연결·실제 브라우저 표시·사용자 승인을 각각 증거로 기록한다. 도구가 막히면 실제 오류와 제한을 보고하고 이미 검증된 경로를 우선 사용한다. 업로드·검증 성공을 보장하거나 미실시 항목을 PASS로 바꾸지 않는다.

## 2026-10-20 개발 링크 반영 승인
사용자는 새 작업과 이번 수정 사항을 유진T 클래스룸 미지의길 개발용 링크에 반영하고 해당 링크에서 확인하도록 명시적으로 요청했다. 개발 미리보기 연결과 배포는 이 승인 범위에서 진행한다. 기존 HOME 이미지·배치와 학생 데이터는 보존하며, 클래스룸 공유 main은 최신 기준에서 미지의길 경로만 PR로 반영한다. 최종 게임 출시 승인으로 확대하지 않는다.

## 2026-10-21 구현 기록 유지
작업별 과거 기록과 최신 상태를 구분한다. 구현·방법·수정·검증·배포 및 미검증 범위는 docs/CURRENT_IMPLEMENTATION_AND_CHANGELOG_20261021.md에 연결하고, 다음 변경마다 함께 갱신한다. 승인 원본·학생 백업 JSON·토큰을 변경 기록에 복제하지 않는다.

## 2026-10-21 새 생성 PNG 검증 경로
내장 생성 결과의 실제 로컬 원본을 확보할 수 있으면 docs/IMAGEGEN_PIPELINE_PROBE_20261021.md의 검증된 Git 바이너리 경로를 사용할 수 있다. 원본 보존·전체 해시·원격 재다운로드·배포 SUCCESS·실제 브라우저 검증을 각각 수행한다. F5는 지원 원본 참조와 큐 성공이 확인된 경우 별도 사용한다. 전송 성공을 최종 디자인 승인이나 상시 자동화로 확대하지 않는다.
